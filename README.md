# Meeting Room Booking System

Веб-приложение для поиска, бронирования и управления переговорными
комнатами.

Пользователь может выбрать офис, найти подходящую переговорную,
посмотреть расписание комнаты, создать бронирование и управлять своими
будущими бронированиями.

## Реализовано по требованиям задания

-   список переговорных комнат с фильтрами;
-   выбор офиса для отображения комнат;
-   просмотр расписания отдельной переговорной;
-   создание бронирования;
-   отмена будущих бронирований пользователя;
-   обработка конфликта бронирования (HTTP 409);
-   real-time обновление данных через WebSocket:
    -   создание бронирования;
    -   отмена бронирования;
    -   изменение доступности комнаты;
-   состояния загрузки, ошибок и пустых данных;
-   unit-тесты для API, хуков и вспомогательной логики.

Ограничения бронирования: - только будущее время; - рабочие часы:
09:00--20:00; - минимальная длительность: 15 минут; - шаг выбора времени
--- 15 минут; - бронирование максимум на 30 дней вперёд; - пересечение
бронирований контролируется backend API.

## Технологии

### Основной стек

-   React --- разработка пользовательского интерфейса;
-   TypeScript --- типизация приложения;
-   Vite --- сборка и запуск проекта;
-   React Router DOM --- маршрутизация;
-   TanStack Query --- работа с серверным состоянием, кеширование и
    обновление данных;
-   Axios --- HTTP-запросы к backend API;
-   WebSocket API --- получение real-time обновлений.

### UI и работа с данными

-   Material UI (MUI) --- UI-компоненты;
-   Emotion --- стилизация компонентов MUI;
-   Day.js --- работа с датами и временем.

### Тестирование

-   Vitest --- запуск unit-тестов;
-   Testing Library --- тестирование React-логики и хуков;
-   JSDOM --- браузерное окружение для тестов.

## Структура проекта

    src/
    ├── api          # работа с backend API
    ├── components   # переиспользуемые UI-компоненты
    ├── hooks        # бизнес-логика и работа с серверными данными
    ├── pages        # страницы приложения
    ├── utils        # вспомогательные функции
    ├── router       # настройка маршрутов
    └── main.tsx     # точка входа

## Маршруты

| Маршрут | Назначение |
|---|---|
| `/` | перенаправление на `/rooms` |
| `/rooms` | список переговорных комнат |
| `/rooms/:roomId` | информация о комнате и расписание |
| `/bookings` | бронирования пользователя |
| `*` | страница "Ничего не найдено" |

## Архитектурные решения

Серверное состояние управляется через TanStack Query. После создания или
отмены бронирования, а также после WebSocket-событий данные обновляются
через invalidate queries.

WebSocket используется для синхронизации открытого расписания и
доступности комнат без перезагрузки страницы.

Логика работы с API вынесена в отдельные hooks, а UI-компоненты отвечают
только за отображение данных.
